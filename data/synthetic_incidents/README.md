# Только синтетическая учебная лаборатория

Все продажи, вмешательства, тяжесть, веса затрат и времена загрузки
искусственные. Здесь нет разметки реальных бизнес-проблем.

Воспроизведение: `python -m scripts.make_incident_demo` из корня проекта.
Назначение колонок, протокол и команды оценки — в `ALERT_INTELLIGENCE.md`.

`labels.csv` хранится отдельно от `observations.csv`. Детектор не получает
метки. `cost_multiplier` — учебный относительный вес эпизода; базовые цены
из `configs/alert_v06.json` применяются при оценке, не при прогнозировании.

`latent_daily.csv` — скрытая истина симулятора для проверки генерации.
Его нельзя передавать детектору как якобы уже доступные наблюдения.
