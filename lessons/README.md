# Практическая лаборатория — урок 01

1. Из корня проекта создайте окружение (если ещё не сделали) и установите зависимости: `pip install -r requirements.txt`.
2. Откройте `lessons/01_baseline_and_anomalies.ipynb` в VS Code с расширением Jupyter или в JupyterLab.
3. Выполняйте ячейки по порядку. Блоки **Задание A–D** выполните самостоятельно.
4. Все числа в уроке относятся к **синтетической** демонстрации.
5. Не публикуйте результаты как оценку коммерческого продукта. Без меток реальных инцидентов нет метрик precision/recall обнаружения.

Ключевой смысл: различать **неожиданное значение**, **ошибку качества данных**, **реальную операционную проблему** и **бухгалтерский убыток**.

## Урок 02 — сравнение моделей (AI-first)

- Открой `02_model_comparison.ipynb` для исполняемого урока.
- Прочитай `02_model_comparison.md` для бизнес-постановки и вопросов на code review.
- Из корня запусти `python -m scripts.compare_models` для HTML-отчёта и CSV.
- Код пишет ИИ; ты проверяешь постановку, временную утечку, валидность метрик и выводы.
